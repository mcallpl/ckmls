Chip is a real estate agent (First Team Real Estate) building a client-facing MLS property search and CMA tool at chipandkim.com/ckmls. He cares deeply about:
- **Data accuracy** — search radius must reflect true geographic distance, not just ZIP code boundaries. Deceptive results are unacceptable.
- **Polished UX** — wants features that "blow minds" (draggable radius, polygon drawing, live updates)
- **Transparency** — wants users to see exactly how many homes exist vs how many are shown
- Checks results against the actual MLS to verify correctness
- Gets frustrated when changes don't take effect (due to caching) — always verify in incognito first
